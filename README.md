# Orbital Observations
 A satellite tracking app developed for the 2026 Congressional App Challenge. Because watching colors race across the Earth is fun!

## How To Run:

If you just want to run the app the without needing Unity:

1. Go to the **[Releases Page](https://github.com/eddiederp/Orbital-Observations/releases)** on the right side of the web page.
2. Download and extract the version specific to your platform (just Windows or Linux right now)
3. Follow installation instructions listed for your platform in the release description.

### Directions to Use:

* Click 'Begin Observing' to enter the app.
* Move camera using the arrow keys.
* To find a specific satellite, enter its NORAD ID in the search bar on the top left of the screen (for example, the International Space Station's ID is 25544) and click away to focus on it.
* Click on any satellite to focus on it.
* To unfocus from a satellite, go to the search bar, delete the ID currently in it, and click off to return to the main Earth view.
* Click the left and right arrows on the top left of the screen to switch categories.
* Click the Home icon to return to the main menu.

## How to Load in Unity:

You'll need Unity Hub and Unity Editor version 6000.5.3f1 to load the project files correctly. To build, you'll need Windows, Linux, and WebGL Build Support.
